# 버킷스탬프

MBTI와 취향, 버킷리스트에 쓸 수 있는 예산과 시간을 입력하면 해낼 수 있는 버킷리스트를 추천해 주고, 단계별로 체크하며 달성해 나가는 웹앱 프로토타입입니다.

- 성향 진단: MBTI 직접 입력 또는 축별 선택, 취향 질문 5개, 관심 분야
- 예산·시간: 총 예산(만원), 기간, 주당 시간으로 쓸 수 있는 시간 계산
- 추천: 성향 일치도와 남은 예산·시간을 함께 고려한 40개 목표 순위
- 내 버킷: 단계 체크리스트, 달성 도장, 직접 추가
- 기록은 브라우저(localStorage)에 저장됩니다. 함께하기·공구 기능은 서버 연결 후 열립니다.

`index.html` 파일 하나로 동작하며, 폰트(Pretendard, SIL OFL)까지 파일 안에 포함되어 있습니다.
