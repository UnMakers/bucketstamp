# 버킷스탬프

MBTI와 취향, 버킷리스트에 쓸 수 있는 예산과 시간을 입력하면 해낼 수 있는 버킷리스트를 추천해 주고, 사진으로 인증하며 하나씩 달성해 나가는 웹앱 프로토타입입니다.

👉 https://unmakers.github.io/bucketstamp/

## 기능
- **성향 진단**: MBTI 직접 입력 또는 축별 선택, 취향 질문 5개, 관심 분야, 사는 지역
- **예산·시간**: 총 예산(만원), 기간, 주당 시간으로 쓸 수 있는 시간 계산
- **추천**: 목표 112개를 카드로 한 장씩 만나며, 장면·이유·맛보기와 함께 끌림을 고르는 발견 경험
- **나만의 버전**: 같은 버킷도 제목·변주·단계를 내 식대로 바꿔 담기, 세상에 하나뿐인 나만의 문양과 리스트 이름
- **비슷한 사람**: 성향·MBTI·예산·시간이 비슷한 예시 인물의 과정과 결과 소개
- **단계 인증**: 사진이나 한 줄 기록을 남겨야 완료, 실제 쓴 돈·시간 기록
- **계획**: 목표일과 단계별 날짜, D-day, 밀린 단계 알림, 폰·구글 캘린더 추가
- **편집**: 버킷 이름·분야·예상 비용과 시간, 단계 이름·순서·삭제·추가
- **달성**: 도장과 달성 카드 이미지(1080×1350) 저장·공유, 단계별 기록 앨범
- **기록 관리**: 사진까지 포함한 백업 파일 저장·불러오기
- **앱처럼 쓰기**: 홈 화면에 추가, 오프라인에서도 열림

기록은 브라우저(localStorage), 인증 사진은 IndexedDB에 저장됩니다. 함께하기·공구 기능은 서버 연결 후 열립니다.

`index.html` 하나에 폰트(Pretendard, SIL OFL)까지 포함되어 있습니다.
